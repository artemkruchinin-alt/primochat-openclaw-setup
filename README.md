# primoChat · OpenClaw на Kimi + SearXNG

Установщик для первого контролируемого пилота. Настраивает **уже установленный OpenClaw 2026.8.1** на Linux с пользовательской службой `openclaw-gateway.service`. Нужны Python 3.10+, OpenSSL, работающий Docker с доступом пользователя OpenClaw и доступ к npm/HTTPS. SearXNG устанавливается автоматически в локальном контейнере; отдельный адрес поиска и API-ключ поиска не нужны. Запускайте под пользователем OpenClaw, без `sudo`.

## Как подключить

1. В primoChat откройте **Studio → OpenClaw → Настроить OpenClaw**.
2. Получите API-ключ в [консоли Kimi Code](https://www.kimi.ai/code/console). Это ключ Kimi Code, а не Moonshot Open Platform.
3. Скопируйте из Studio команду скачивания и проверки SHA-256. Она закреплена за конкретной версией скрипта. Запустите её в терминале вашего сервера.
4. Укажите аккаунт primoChat и введите ключ Kimi в скрытое поле терминала. Скрипт проверит небольшой тестовый ответ.
5. Когда скрипт попросит код, получите его в Studio и вставьте в терминал. Код одноразовый, действует 10 минут.
6. Дождитесь проверки Kimi через OpenClaw. Напишите обычное сообщение в новом чате помощника и подтвердите содержательный ответ в Studio. Отдельно попросите найти свежую информацию и привести ссылки.

[Реферальная ссылка Kimi](https://www.kimi.ai/activities/en/invite/share?scenario=subscribe&from=share_poster&invitation_code=3F635E) — по желанию, для регистрации или подписки. Получение ключа доступно по отдельной прямой ссылке выше. Условия акции определяет Kimi.

## Варианты размещения

Этот установщик предназначен для сервера пользователя. Платный хостинг primoChat — отдельный планируемый вариант: вход и ключ Kimi в Studio, изолированный агент с поиском на нашей стороне. Платный вариант ещё недоступен.

## Что меняется

- Модель по умолчанию и модель агента `main`: `kimi/kimi-for-coding`, международный адрес Kimi Code `https://api.kimi.ai/coding/`.
- Matrix-канал этого профиля заменяется новым подключением, ограниченным вашим аккаунтом и отдельным чатом. Другие каналы и настройки инструментов сохраняются.
- SearXNG запускается из официального образа, закреплённого по digest, с портом только на `127.0.0.1`. Лимиты контейнера: 512 МБ RAM и 1 CPU. Поисковые запросы уходят выбранным внешним поисковым системам. Контейнер `primochat-openclaw-search-<uid>` повторно используется и остаётся запущенным при ошибке подключения чата; никаких пользовательских сообщений в его проверку не передаётся.
- Официальный плагин `@openclaw/searxng-plugin@2026.8.1` подключает поиск.
- Официальный Matrix-плагин устанавливается из npm версии `2026.8.1`, если отсутствует, и включается.
- Ключ Kimi и токен помощника остаются в файле с правами `0600`, каталог имеет права `0700`. Studio не получает эти ключи. Сообщения чата помощника передаются Kimi для ответа; сквозное шифрование этого чата отключено.
- Перед записью конфигурации служба останавливается; создаётся зашифрованная копия конфигурации и отдельный локальный ключ её восстановления. При штатной ошибке скрипт восстанавливает конфигурацию и прежнее состояние службы.

История чатов не удаляется. Замена локальных настроек прекращает работу старого подключения на этом сервере, **но не отзывает старый Matrix-токен на сервере**. Управляемое новое подключение можно отозвать кнопкой «Отключить помощника» в Studio. Старое ручное подключение отзывается отдельно после проверки нового.

## Если настройка прервалась

Не присылайте ключи, содержимое конфигурации или файлы `~/.openclaw/primochat-setup/` в поддержку. При ошибке Kimi проверьте ключ, подписку и регион в консоли. Скрипт не пробует отправлять ключ на другой региональный адрес.

Потерянный/использованный код перевыпускается в Studio: «Новый код» отзывает прежний доступ этого помощника. Повторный запуск создаёт отдельный каталог попытки и не перезаписывает секреты прошлой. Не запускайте два установщика одновременно. При отключении питания или принудительном завершении автоматический откат не гарантируется; остановите службу и обратитесь к оператору с текстом этапа без ключей. Копия `config.enc` и ключ `backup.key` лежат в каталоге соответствующей попытки.

Этот пилот не устанавливает OpenClaw с нуля и не поддерживает root, OpenClaw внутри Docker, несколько агентов/Matrix-аккаунтов, пользовательские профили и конфигурацию JSON5/include. Такие конфигурации останавливаются до изменения подключения. Успешная локальная проверка не заменяет тест реального ответа в primoChat.
